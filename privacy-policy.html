🛡️ CampusGuard — Privacy Policy

Last updated: April 2, 2026

1. Overview

CampusGuard is a campus safety monitoring application that uses on-device artificial intelligence to detect potential threats via your device's camera. This policy describes what data we collect, how it is used, and your rights.

2. Camera Access

  • CampusGuard accesses your device camera solely to perform on-device AI threat detection using ONNX Runtime and MediaPipe.
  • No video is streamed, recorded, or stored in the cloud.
  • All AI inference runs locally on your device. No raw camera data leaves the device during normal operation.

3. Data Collected

When an operator confirms a detected threat (by tapping "Yes" or "Maybe"), the following data is sent to the server you configure:

  • A single JPEG frame — a screenshot captured at the moment of detection.
  • Event metadata — event type (e.g., "Knife Detected"), AI model confidence score, operator verdict, and timestamp.
  • Device ID — a device-specific Android identifier used to distinguish reporting devices.
  • AI threat analysis — if the optional on-device TinyLlama LLM model is loaded, a short text-based threat assessment may be included.

No data is transmitted without explicit operator confirmation.

4. On-Device AI

  • CampusGuard uses YOLOv8 (via ONNX Runtime) for real-time object detection and TinyLlama 1.1B (via MediaPipe) for optional threat analysis.
  • Both models run entirely on your device. No data is sent to any AI cloud service for inference.
  • The TinyLlama model is an optional download (~1.1 GB) from HuggingFace and is stored locally on your device.

5. Server Communication

  • The app communicates with a user-configured backend server URL using a token-based authentication header (x-campusguard-token).
  • You control which server receives your data. No default server is pre-configured.
  • All server communication uses HTTPS encryption.

6. Third-Party Services

  • CampusGuard does not include any advertising SDKs.
  • CampusGuard does not include any third-party analytics or tracking libraries.
  • No data is shared with or sold to any third party.

7. Data Retention

  • Alert data sent to the server is managed by the server operator (your institution or organization).
  • Local alert history is stored on your device and can be cleared at any time from the app's Alert History screen.

8. Your Rights

  • You can revoke camera permission at any time through your device's Settings.
  • You can clear local alert history from within the app.
  • You can disconnect from the server by clearing the server URL in the app's Settings.
  • You can request deletion of server-side data from your server administrator.

9. Children's Privacy

CampusGuard is intended for use by authorized campus security personnel and is not designed for use by children under 13.
